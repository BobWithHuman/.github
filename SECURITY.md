# Security Policy

## Reporting a Vulnerability

If you think you have discovered a security issue, **please do NOT open a public issue.**

Instead, report it privately through the repository's **Security → Report a vulnerability** menu (GitHub Private Vulnerability Reporting).

- withhuman-core: https://github.com/BobWithHuman/withhuman-core/security/advisories/new

To help us respond quickly, please include:

- The type of vulnerability and its impact
- Steps to reproduce
- Related file paths, versions, or commits
- A proof of concept or suggested fix, if possible

We will get back to you as soon as possible. Please do not disclose the issue publicly until a fix has been released.
